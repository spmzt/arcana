# RFC 8343 — A YANG Data Model for Interface Management (ietf-interfaces, NMDA)

Source: /tmp/claude-0/-home-user-arcana/c5b51962-0391-52a9-87d4-18bb94158d90/scratchpad/rfc/rfc8343.txt (March 2018, obsoletes 7223; 2321 compact lines, read in full).

## Purpose
Generic, flat list of interfaces (`/interfaces/interface[name]`) with config (`type`,
`enabled`, `description`) and operational state (admin/oper status, if-index, phys-address,
layering, speed, IF-MIB counters) merged into one tree per NMDA. Interface-type-specific
modules (ethernet, vlan, lagg, tunnel...) augment the list conditionally on `type`
(identities from `iana-if-type`, RFC 7224). `/interfaces-state` is deprecated (non-NMDA
compatibility only).

## Terminology and rules
- **system-controlled interface**: created/deleted by the system (physical NICs, `lo0`);
  always present in `<operational>`; config with the same `name` is applied if type matches,
  otherwise the interface exists without explicit config.
- **user-controlled interface**: exists because of configuration (vlan, epair, bridge, lagg,
  gif, tun, wg...); name comes from the configuration. Feature `arbitrary-names`: the server
  allows any name for user-controlled interfaces (FreeBSD: `ifconfig <if> name foo` works,
  but creation requires a driver-prefixed name `vlan0`/`epair0a`; so FreeBSD is "restricted
  names" unless the agent does create-then-rename — Appendix F.4 vs F.5).
- Feature `pre-provisioning`: configuration for hardware not present is accepted (FreeBSD:
  rc.conf `ifconfig_em3=...` for an absent card is accepted → advertise it).
- Feature `if-mib`: `if-index`, `admin-status`, `link-up-down-trap-enable` present (FreeBSD
  has ifindex → advertise it; `admin-status` = IFF_UP).
- `type` mandatory; server MAY auto-initialise it from the name (F.1/F.4); setting a type
  that cannot match the name → `invalid-value`.
- Config for a system-controlled interface not present and not pre-provisionable →
  `invalid-value`.
- `interface-ref` typedef = leafref to `/if:interfaces/if:interface/if:name` — the
  reference type every other module uses (ip, routing, ni, lne, sn).
- Layering: `higher-layer-if*`/`lower-layer-if*` read-only; type-specific modules model
  the configured layering (vlan `base-interface`, lagg `slave-if`).
- `link-up-down-trap-enable` default behaviour: enabled for interfaces with no lower layer.
- Counters 64-bit only; `discontinuity-time` mandatory in `statistics`.

## Tree (section 3) verbatim
```
module: ietf-interfaces
  +--rw interfaces
     +--rw interface* [name]
        +--rw name                        string
        +--rw description?                string
        +--rw type                        identityref
        +--rw enabled?                    boolean
        +--rw link-up-down-trap-enable?   enumeration {if-mib}?
        +--ro admin-status                enumeration {if-mib}?
        +--ro oper-status                 enumeration
        +--ro last-change?                yang:date-and-time
        +--ro if-index                    int32 {if-mib}?
        +--ro phys-address?               yang:phys-address
        +--ro higher-layer-if*            interface-ref
        +--ro lower-layer-if*             interface-ref
        +--ro speed?                      yang:gauge64
        +--ro statistics
           +--ro discontinuity-time    yang:date-and-time
           +--ro in-octets?            yang:counter64
           +--ro in-unicast-pkts?      yang:counter64
           +--ro in-broadcast-pkts?    yang:counter64
           +--ro in-multicast-pkts?    yang:counter64
           +--ro in-discards?          yang:counter32
           +--ro in-errors?            yang:counter32
           +--ro in-unknown-protos?    yang:counter32
           +--ro out-octets?           yang:counter64
           +--ro out-unicast-pkts?     yang:counter64
           +--ro out-broadcast-pkts?   yang:counter64
           +--ro out-multicast-pkts?   yang:counter64
           +--ro out-discards?         yang:counter32
           +--ro out-errors?           yang:counter32
```
Deprecated `/interfaces-state` (config false) repeats name, type, admin-status,
oper-status, last-change, if-index, phys-address, higher/lower-layer-if
(`interface-state-ref`), speed, statistics — identical leaves with `status deprecated`.

Module `ietf-interfaces@2018-02-20`, yang-version 1.1, prefix `if`, imports
`ietf-yang-types`. Identity `interface-type` (base). Features `arbitrary-names`,
`pre-provisioning`, `if-mib`. Typedefs `interface-ref`, `interface-state-ref` (deprecated).
Enumerations: `link-up-down-trap-enable` enabled(1)/disabled(2); `admin-status`
up(1)/down(2)/testing(3), mandatory; `oper-status` up(1)/down(2)/testing(3)/unknown(4)/
dormant(5)/not-present(6)/lower-layer-down(7), mandatory; `if-index` int32 range
1..2147483647 mandatory; `enabled` default true; `speed` units bits/second.
IF-MIB table: name↔ifName, type↔ifType, description↔ifAlias, admin-status↔ifAdminStatus,
oper-status↔ifOperStatus, last-change↔ifLastChange, if-index↔ifIndex, phys-address↔
ifPhysAddress, higher/lower-layer-if↔ifStackTable, speed↔ifSpeed/ifHighSpeed,
discontinuity-time↔ifCounterDiscontinuityTime, counters↔ifHC*/if*.
SID range (RFC 9595): ietf-interfaces 1500, size 100; iana-if-type 1800, size 400.

## Appendix examples
A: `example-ethernet` augment with `when "if:type = 'ianaift:ethernetCsmacd'"`, container
`ethernet/transmission` choice auto|manual{duplex, speed}, ro `duplex`.
B: bonding `slave-if*` leaf-list with `must "/if:interfaces/if:interface[if:name = current()]/if:type = 'ianaift:ethernetCsmacd'"`.
C: vlan `vlan-tagging` on ethernet/lag, `base-interface` with must on vlan-tagging,
`vlan-id uint16 1..4094` with `must "../base-interface"`.
D/E: get-config and get-data replies with `or:origin` (`intended`, `system` for an
unconfigured eth2).

## FreeBSD mapping, node by node
| Node | FreeBSD source (operational) | FreeBSD sink (running → intended) |
|---|---|---|
| `interface[name]` | `getifaddrs(3)` / `SIOCGIFCONF` / `if_nameindex(3)`; netlink `RTM_GETLINK` (FreeBSD 13.2+ `netlink(4)`, `snl(3)`) | rc.conf `ifconfig_<name>=`, `cloned_interfaces=` (user-controlled); `SIOCIFCREATE2` / `SIOCIFDESTROY` |
| `name` | `ifr_name` / `ifa_name`; `IFLA_IFNAME` | key; `ifconfig <old> name <new>` (`SIOCSIFNAME`) if arbitrary-names |
| `description` | `SIOCGIFDESCR` (`ifr_buffer`); `IFLA_IFALIAS` | `ifconfig <if> description`; rc.conf `ifconfig_<if>="... description ..."` |
| `type` | `ifm_data.ifi_type` (`IFT_ETHER`, `IFT_LOOP`, `IFT_L2VLAN`, `IFT_BRIDGE`, `IFT_IEEE8023ADLAG`, `IFT_GIF`, `IFT_TUNNEL`, `IFT_PROPVIRTUAL` for epair/tap/wg...) via `SIOCGIFMEDIA`/sysctl `net.link.generic.ifdata.<idx>.general` or `getifaddrs` `AF_LINK` `sdl_type`; `IFLA_INFO_KIND` | identity `ianaift:*` ↔ `IFT_*` table; the cloner name prefix (`vlan`, `bridge`, `lagg`, `epair`, `gif`, `gre`, `tun`, `tap`, `wg`, `ovpn`, `vxlan`) decides `SIOCIFCREATE2` |
| `enabled` | `IFF_UP` in `ifr_flags` (`SIOCGIFFLAGS`) | `ifconfig <if> up/down` (`SIOCSIFFLAGS`); rc.conf keyword `up`/`down` |
| `link-up-down-trap-enable` | n/a (bsnmpd `snmp_mibII` has it); report `enabled` for no-lower-layer ifs | no sink; deviate `not-supported` or accept and ignore |
| `admin-status` | `IFF_UP` → up/down | — |

| `last-change` | `ifi_lastchange` (`struct if_data`, timeval since boot → date-and-time) | — |
| `if-index` | `if_nametoindex(3)`, `ifi_index` | — |
| `phys-address` | `AF_LINK` sockaddr_dl `LLADDR()`; `IFLA_ADDRESS` | (`ifconfig <if> ether xx:..` is an ethernet-module augmentation, not here) |
| `higher-layer-if` | vlan children (`SIOCGETVLAN` per vlan matches `vlr_parent`), bridge membership (`BRDGGIFS` via `SIOCGDRVSPEC`), lagg ports (`SIOCGLAGG`); `IFLA_LINK`/`IFLA_MASTER` with netlink | — |
| `lower-layer-if` | vlan `vlr_parent`; lagg member's `laggport`; bridge members; `IFLA_LINK` | — |

| `in-unicast-pkts` | `ifi_ipackets − ifi_imcasts` (FreeBSD has no separate broadcast counter; `imcasts` includes broadcast) | |
| `in-broadcast-pkts` | not available separately → omit leaf | |
| `in-multicast-pkts` | `ifi_imcasts` | |
| `in-discards` | `ifi_iqdrops` | |
| `in-errors` | `ifi_ierrors` | |
| `in-unknown-protos` | `ifi_noproto` | |
| `out-octets` | `ifi_obytes` | |
| `out-unicast-pkts` | `ifi_opackets − ifi_omcasts` | |
| `out-broadcast-pkts` | not available → omit | |
| `out-multicast-pkts` | `ifi_omcasts` | |
| `out-discards` | `ifi_oqdrops` (`if_get_counter(IFCOUNTER_OQDROPS)`) | |
| `out-errors` | `ifi_oerrors` | |
Counters: `struct if_data` via `getifaddrs` `ifa_data`, or `sysctl net.link.generic.ifdata.<idx>.general` (`IFDATA_GENERAL`), or `netstat -i --libxo json` (what the agent uses today), or netlink `RTM_GETLINK` `IFLA_STATS64` (FreeBSD 14 netlink fills `rtnl_link_stats64`).

Origin annotation (`ietf-origin`): interfaces present in rc.conf → `intended`; physical
interfaces not configured → `system`; `enabled` absent in config → `default`;
`description` set by `ifconfig` by hand → `dynamic`? No — `unknown`/`system` since the
agent cannot tell; Arcana's existing live-vs-persistent address distinction is exactly
`operational` vs `running`.

Event source for on-change (RFC 8641): `PF_ROUTE` socket messages `RTM_IFINFO` (flags,
link state), `RTM_IFANNOUNCE` (arrival/departure), `RTM_NEWADDR/DELADDR`; or netlink
`RTNLGRP_LINK`/`RTNLGRP_IPV4_IFADDR`/`RTNLGRP_IPV6_IFADDR` multicast groups. devd also
emits `IFNET <if> LINK_UP/LINK_DOWN/ATTACH/DETACH`.

Jails: for a VNET jail the same code runs with the jail attached (`jail_attach(2)` in a
forked helper, or `ifconfig -j <jail>`, `netstat -j`, FreeBSD 14+; netlink socket opened
after `jail_attach`); non-VNET jails see the host's `ietf-interfaces` with their
`ip4.addr` aliases appearing as `ietf-ip` addresses on the host interface.

## Arcana-specific augmentations to define (one module `arcana-interfaces`)
- `when "if:type = 'ianaift:l2vlan'"`: `vlan-id`, `parent` (like Appendix C; sinks
  `SIOCSETVLAN`, rc.conf `vlans_<parent>=`).
- `when "if:type = 'ianaift:bridge'"`: `member*` interface-ref, stp flags (`BRDGADD`,
  rc.conf `ifconfig_bridge0="addm em0 addm em1"`).
- `when "if:type = 'ianaift:ieee8023adLag'"`: `laggproto`, `laggport*`.
- `epair`: `peer` interface-ref, `vnet` (leafref to jail / lne name) — the hook into
  RFC 8530 `bind-lne-name`.
- `mtu` lives in `ietf-ip` per address family; link MTU (`SIOCSIFMTU`) could be an
  `arcana-interfaces:mtu` augment since RFC 8343 deliberately leaves ifMtu out.
- `ether` (MAC override) under an ethernet augment, `media`/`mediaopt`, `groups`
  (`SIOCAIFGROUP`), `fib` (→ RFC 8529 `bind-ni-name`), `promisc`, `txcsum`/`rxcsum`/`tso`/
  `lro` capability flags as a `bits` leaf (`SIOCSIFCAP`).

bia-mac-address; the FIB is RFC 8529's bind-ni-name; an epair end's
other is `ietf-if-extensions`' peer-interface. A vlan's, a lagg's and a

IEEE 802.1Q, the media to IEEE 802.3, `arcana-interfaces` keeping
FreeBSD's own beside them.
